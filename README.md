# Regular Investing in BOX - Notes de lecture

Notes et résumé du livre "定投改变命运" (Regular Investing Changes Fate) de Li Xiaolai.

**Source**: https://github.com/xiaolai/regular-investing-in-box

## Fichiers

- [resume.md](./resume.md) - Résumé général du livre et concepts clés
- [tips-pratiques.md](./tips-pratiques.md) - Les conseils concrets extraits du livre
- [verdict.md](./verdict.md) - Analyse critique: ce que le livre est vraiment

## TL;DR

Ce livre n'est **pas** un guide de trading. C'est un manifeste philosophique sur le DCA (Dollar-Cost Averaging) avec une forte promotion du produit BOX de l'auteur.

> "Choisis le meilleur actif évident, investis régulièrement ce que tu peux te permettre, tiens 2 cycles complets, ignore tout le reste."
